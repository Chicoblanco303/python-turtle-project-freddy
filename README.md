
# Freddy Bear - Python Turtle Graphics

## About the Project
This is a Python Turtle graphics project that draws a Freddy Bear-inspired character using Python's built-in `turtle` module.

The drawing includes:
- A bear character with a head and body
- Eyes, ears, cheeks, and a nose
- A black top hat with a red band
- A blue bow tie
- A moon and green ground
- A greeting caption

## Technologies Used
- Python 3.14
- Python Turtle Graphics
- Python IDLE

## How to Run
1. Install Python 3.14 or another compatible Python 3 version.
2. Download or clone this repository.
3. Open `main.py` in Python IDLE.
4. Select Run > Run Module, or press F5.
